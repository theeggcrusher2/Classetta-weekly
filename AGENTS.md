# Project memory

- When in doubt, follow the Apple Human Interface Guidelines. Reference
  copies live in `kb/` as searchable markdown (see `kb/README.md`): the
  1987 *Human Interface Guidelines: The Apple Desktop Interface* and the
  System 7 era *Macintosh Human Interface Guidelines*. This project
  emulates a System 6/7 Macintosh, so the classic books apply directly.
