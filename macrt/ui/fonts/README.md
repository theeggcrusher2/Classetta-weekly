# Fonts

The Filer's own chrome (titles, menu bar, body text) prefers fonts in this
directory over the host's: a Mac lookalike here is drawn as a crisp bitmap
font, where the fallback to a host font is antialiased. Drop more
Chicago/Geneva lookalikes in as .ttf/.otf and `theme` picks them up —
nothing to register.

- `chicagoflf.ttf` — ChicagoFLF, Robin Casady's revival of Susan Kare's
  Chicago, the System 7 interface font. From the Open Font Library
  <https://usemodify.com/fonts/chicago/>, licensed under the SIL Open Font
  License 1.1 (`OFL-1.1.txt`).
